# 账号直链（accountdl）

FluxDown 插件：用你**在浏览器里已登录**的账号，把网盘分享、哔哩哔哩视频、Pixiv 作品、知网论文解析为直链交给 FluxDown 下载。插件不登录、不保存账号密码。

## 工作方式

1. 在 FluxDown 安装本插件，并在 FluxDown 浏览器扩展的选项页「页面脚本」中启用它。Chrome 138 以上还需在扩展详情页打开「允许用户脚本」。
2. 打开站点页面，点右下角的「直链下载」按钮。
3. 扩展把任务连同浏览器里该站点的 Cookie 交给 FluxDown，插件以你的身份请求站点接口，取得直链后开始下载。多文件分享会先列出清单，供你勾选。

登录态失效时会报「请先在浏览器登录…」，重新登录后从网页再点一次即可。续传沿用任务创建时的 Cookie。

## 支持范围

| 站点 | 入口 | 说明 |
|---|---|---|
| 百度网盘 | 分享页 `pan.baidu.com/s/…`、`/share/init` | 先把文件转存到你网盘的 `/accountdl-tmp/…`，取到直链后立即删除。转存时暂占空间，空间不足会报错。下载使用安卓客户端 UA，单次 Range 不超过 4~5 MiB；连接数按会员等级 1 / 10 / 15，免费账号很慢。 |
| 夸克网盘 | 分享页 `pan.quark.cn/s/…` | 优先免转存取链；被拒时转存到 `accountdl-tmp`，超过 6 小时的副本在下次转存时清理。单线程限速约 100 KB/s，靠多线程提速：SVIP 32、VIP 16、其他 8。 |
| 123 云盘 | 分享页（`123pan.com` / `123pan.cn` 等） | 登录令牌在分享页的浏览器存储里，点按钮时交给插件，明文保存在 FluxDown 插件存储中；过期或退出登录后，下次点击时清除。已登录时消耗你自己的下载流量；未登录时，只有分享者开启了流量包的分享能下载。只解析整个分享。 |
| 115 网盘 | 分享页 `115.com` / `115cdn.com` / `anxia.com` 的 `/s/…` | 必须登录。不转存，也不改动你的网盘；总是解析整个分享。链接里没有提取码时会弹窗询问。 |
| 蓝奏云 | 分享页按钮，或在 FluxDown 里直接粘贴链接（提取码写成 `?pwd=`） | 免登录。支持单文件、带提取码的文件和文件夹。含子文件夹的会员分享需要分别打开子文件夹链接。IP 被风控时需要稍后重试。 |
| 哔哩哔哩 | 视频页（BV / av，含分 P）、番剧和影视页（`ep` / `ss`）；也可直接粘贴链接 | 按账号权限取画质，未登录最高 1080P。视频和音频分开下载，由 FluxDown 用 ffmpeg 合并。多 P 或整季会出清单。画质、编码、音频可在插件设置中选择。 |
| Pixiv | 作品页「下载原图」；也可直接粘贴链接 | 支持插画、漫画（多页出清单）、动图（原始 ugoira zip 帧包）。R-18 或仅登录可见的作品需要登录。 |
| 知网 | 文献详情页 `kns.cnki.net/kcms2/article/abstract…` | 下载 PDF / CAJ，文件名用论文标题。需要账号或机构 IP 本身有下载权限；没有权限或触发验证时，任务因服务器返回 HTML 而失败。 |

各站点都只下载你的账号在网页上本来就能下载的内容。

所有网盘文件夹单次最多列出 1000 个文件、发约 20 次请求，超出时请进入子目录分批下载（115 和 123 云盘不能指定子目录）。

## 已知限制

- 网盘、B 站、Pixiv 的接口都不是公开接口，站点改版后会失效，表现为「返回的不是 JSON」一类错误。
- 不支持：网盘自有文件（非分享）、B 站互动视频 / 课程 / 直播 / `b23.tv` 短链、Pixiv 画师批量与小说、知网学位论文分章下载、高校 WebVPN 代理域名。
- 已与 DiskDirect 分离：本插件的网盘任务使用专属路径 `/__accountdl/…`，在 FluxDown 里粘贴网盘分享链接仍由 DiskDirect 处理。

## 开发

```sh
bun install
bun test && bun run typecheck && bun run build && bun run validate
bun run pack   # → accountdl@accountdl-<版本>.fxplug
```

FluxDown 设置 → 扩展 → 插件 → 从目录安装 → 选 `dist/`。
